## Parked (not targets)

- `microsoft/VibeVoice` (MIT) — 0.5B realtime exists but diffusion-head, Python/vLLM stack, no ggml/ONNX/Rust port. Revisit on any port.
- VoxCPM2 (OpenBMB, Apache-2.0) — 2B diffusion-AR, CPU-hostile. GPU-lane material only.

## Decode policies ported exactly, never simplified

- Phonon: temperature 0.3 (flow start-noise variance), `eos_threshold` EOS head, ~50 text-token chunks at sentence boundaries, >200-token chunks split at clause marks, single words cut between characters; voice = (num_frames, 512) speaker latents prepended per chunk.
- OuteTTS lesson stands (64-token repetition-penalty window) for any future LM lane.
- PocketTTS: `text_chunking.py` policy when its checkpoint is enabled.

## Evaluation targets (who judges us)

- Round-trip WER: `transcription_engine` lane judges our output (nemo int8 default; parakeet q8_0 secondary; temp 0, fixed corpus, te repo WER conventions).
- Corpus: internal bench sentences + `gradium/tts-hard-sentences-202610` (public hard-text set: numbers, dates, codes, units).
- Baseline to beat or justify against: Kokoro-ORT numbers from T005 on the Zen 2 box.

## Hardware reference

- Dev/target box: Zen 2 4800H 8C/16T (same class as te reference numbers: RTF 0.10–0.22, WER 14–18%).
- Weights cache env: `HF_HOME=/teranux/hugging_face`. Weights load off disk (mmap-first) — never bake into memory without the standard-load comparison.

## License asymmetries to respect

- Phonon-31m Apache-2.0 (commercial OK); ALL phonon-40m = CC BY-NC 4.0 + HF-gated → 40m never a default target.
- Speaker codec not released → no on-device cloning on Phonon; cloning belongs to chatterbox lane.
- Voices have per-voice terms (gradium/phonon-voices, kyutai/tts-voices) — record per bundled voice.
- **Chatterbox bundled shipped voice provenance (recorded 2026-11-06, T010 close)**: `VoiceRef::Default` = the model bundle's `conds.pt` conditioning tensors ("Boba's voice") shipped inside `ggml-org/chatterbox-turbo-GGUF` (converted by llama.cpp from Resemble AI's MIT Chatterbox Turbo; Resemble weights = MIT, llama.cpp = MIT, upstream README acknowledges the bundled voice). Stored here per the per-voice-terms rule.

(2) llama.cpp upstream supports Chatterbox Turbo + Multilingual V3 natively, ggml-org publishes prebuilt GGUFs (`chatterbox-turbo-Q8_0.gguf` 481.8 MB + `mmproj-chatterbox-turbo-F16.gguf` 555.4 MB, converted 2026-11-05), and the frozen `llama.h`/`mtmd.h` C libs carry the whole stack. (3) TTS orchestration = `mtmd_helper::gen_audio` (C++, tools/tts/tts.cpp = 243-line thin client) → FFI = workspace-side C++ shim `extern "C"` wrapping the exact tts.cpp recipe, linking static libllama+libmtmd+ggml. - [x] phonon-40m gate terms — **resolved 2026-11-06**: weights = **CC BY-NC 4.0** (full International text confirmed via the model's shipped license blob); gradium's own table (gradium.ai/phonon): 31m Apache-2.0 / 40m + 40m-multilingual "CC BY-NC — for commercial use, talk to sales". Gate mechanics (rhapsode docs + HF tree): per-repo HF gate — logged-in user must **accept terms on each 40m repo's page** before download; anonymous users can list files but not fetch them (API metadata itself 401s without auth: `huggingface.co/api/models/gradium-ai/phonon-40m` → "Invalid username or password"). Consequence: 40m = eval/experiment-only material under non-commercial terms; never a default/bundled target; any commercial use routes through gradium sales.
- [x] pocket-tts code LICENSE before vendoring anything from kyutai-labs Rust — **resolved 2026-11-06: MIT.** Root `LICENSE` (1023 chars) is the plain MIT text (Kyutai ships it without a `Copyright (c)` attribution line); the standalone `rust/` subcrate independently declares `license = "MIT"` in Cargo.toml ("Kept in step with the Python package in ../pyproject.toml"). Vendoring the Rust CLI is license-clean. Caveat for any port: the shipped Rust binary builds on a forked ptts (`gabrieldemarmiesse/xn-ptts` @ `7efa269…`, pocket-tts-small-models branch) + `xn 0.2.11`, not our pinned `ptts 0.6.0`.
- [x] Phonon/PocketTTS Mimi decoder safetensors layout equivalence — **resolved 2026-11-06, measured locally: EQUIVALENT decoder layout.** Phonon `models/phonon-31m-en/model.safetensors` → prefixes {mimi: 44, flow_lm: 141}; pocket `kyutai/pocket-tts-without-voice-cloning` main blob (209 MB, 213 tensors) → {mimi: 87, flow_lm: 127}. **All 44 phonon `mimi.*` tensor names present in pocket with identical shapes** (zero name-only, zero shape mismatch). Differences: (a) dtype — pocket stores Mimi in **BF16**, phonon in F32 → loader casts BF16→F32 (candle-native); (b) pocket additionally ships the **encoder side** (`encoder.model.*` SEANet + `encoder_transformer` 2L + `downsample.conv`) which phonon's checkpoint omits (TTS needs decode only); (c) weight VALUES differ (sha256 spot-check on 5 decoder tensors — different fine-tunes, as expected; layout equivalence ≠ interchangeable outputs). Consequence: candle `mimi.rs` decoder can target pocket checkpoints with a dtype cast, no relayout; per-checkpoint decode correctness still gated by a parity probe (T008 law).
- [x] G2P choice for Kokoro lane: espeak-ng vs misaki — **resolved 2026-11-05 (T004): espeak-ng subprocess** (the misaki espeak-fallback materialization), phonemizer-style punctuation restore + vocab filter; GPL-caveat = subprocess invocation (no linking), `TTS_ESPEAK` override. piper lane (T011) uses espeak-rs 0.2 IN-PROCESS vendored espeak-ng 1.52.0.1 instead — GPLv3 LINKING caveat documented in that lane's contract block.
